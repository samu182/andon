# andon（あんどん）

複数のプロジェクトにまたがるシステムの構成図を、計画の進み具合と重ねて見るための窓です。
Rust と [egui](https://github.com/emilk/egui) で書き、CPU だけで描きます（メモリは約 30 MB）。

[claude-code-kanban](https://github.com/samu182/claude-code-kanban) と組で動きます。
カンバンの `board.py` が組み立てた状態（`~/.herdr/kanban-state.json` の `arch`）を読んで描くだけで、判断は持ちません。

## 何に困っていたか

AI（Claude Code）と並行して作業していると、「どの部品がどこまで本番で動いているか」「今どこを触っているか」「設計の図と現物がずれていないか」が、頭の中にしか無くなっていました。
計画書は項目の表なので、部品どうしのつながりは見えません。

## 何ができるか

- **構成図に計画の状態を重ねる。** 部品の地の色が、その部品に結びついた計画書の項目の状態を表します
- **今どこを触っているかが分かる。** ターミナル（herdr）のペインのブランチ → PR → カード → 部品とたどり、作業中の部品に青いライトを灯します
- **ずれを出す。** 図に無い計画、設計が変わったのに図が古いもの、前回から変わったものを一覧にします
- **ウォーキングスケルトン。** 最初の区切りに要る部品の並びを下の帯に出し、矢印キーでたどれます
- **完成図。** 作るかは未定の部品（構想。カンバンの `arch-future.json`）を、上の帯の「今｜完成図」か `k` で薄い点線として重ねます。既定は今の図で、構想は今の図の状態・ずれ・骨格・並び方に一切効きません。切り替えは全部のタブで共通です
- **書き出す。** 今のタブを、ブラウザで操作できる 1 枚の HTML にします（`e`）。人に渡す用（`Shift+E`）は、AI に渡す文・ブランチ・確かめた結果などの手元の情報を抜きます

## 作りで気をつけたこと

- **判断と描画を分ける。** 何をどの状態で出すかは Python 側（テストあり）で決め、この窓は描くことと操作だけにしています
- **軽くする。** GPU のドライバーを読み込まないよう CPU で描く部品を使い、メモリを約 95 MB から約 30 MB に減らしました。比べるために GPU 版（eframe + glow）にも切り替えられます
- **窓は 1 つ。** タブは最初から全体と全部のプロジェクト（`kanban.json` の `"order"` の順）で、閉じません。2 回目に起動すると、開いている窓のそのプロジェクトのタブに切り替えて前に出します

## ビルド

```
cargo build --release                                  # CPU で描く版（既定）
cargo build --release --no-default-features --features gpu   # GPU で描く版
pwsh install.ps1 -Build                                # ビルドして ~/.herdr/bin に置く
```

`vendor/egui_software_backend` は、CPU で描く部品に手を入れたものです（MIT / Apache-2.0。元のライセンスファイルを同梱しています）。
